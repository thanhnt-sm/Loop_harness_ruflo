## 1. Objective

Implement **durable execution layer** for AHD sessions to enable:
- **Checkpoint state after each phase** → resume from last completed phase
- **No redo paid LLM calls** on crash/restart
- **Idempotency keys + receipts** for tool calls
- **Human-gated saga** for irreversible operations

Based on BUILD_LONG_SESSION_2026.md patterns: DBOS-style lightweight checkpointing (Postgres/library), not full Temporal cluster.

## 4. Implementation Details

### 4.1 ahd_session.py — Extended with Workflow Tracking

```python
# Phase definitions
class SessionPhase(Enum):
    BOOT = "boot"
    PLAN = "plan"
    APPROVE_SDD = "approve_sdd"
    APPROVE_PLAN = "approve_plan"
    EXECUTE = "execute"
    VERIFY = "verify"
    REPORT = "report"
    COMPLETED = "completed"

# Checkpoint structure
@dataclass
class DurableCheckpoint:
    session_id: str
    phase: SessionPhase
    step_index: int
    goal: str
    completed_steps: list[dict]  # {phase, step, llm_calls_cached, receipts}
    pending_waits: list[dict]    # {type: "approval"|"webhook", ref, payload}
    receipts: list[dict]         # {idempotency_key, tool, args, result}
    compact_state: dict          # goal, phase, waits, receipts (no full history)
    created_at: datetime
    llm_call_cache: dict         # {call_hash: response} for deduplication
```

### 4.2 state_store/file_backend.py — Durable Checkpoint Persistence

```python
def save_checkpoint(session_id: str, checkpoint: DurableCheckpoint) -> None:
    """Atomically write checkpoint to disk."""
    path = _checkpoint_path(session_id)
    tmp = path.with_suffix(".tmp")
    tmp.write_text(json.dumps(asdict(checkpoint), default=str))
    tmp.replace(path)

def load_checkpoint(session_id: str) -> DurableCheckpoint | None:
    """Load latest checkpoint for resume."""
    path = _checkpoint_path(session_id)
    if not path.exists():
        return None
    return DurableCheckpoint(**json.loads(path.read_text()))
```
