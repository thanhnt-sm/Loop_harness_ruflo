Implement **eval harness layer** to make AHD competitive with Claude/Codex/GPT harnesses:

- **V1**: Private versioned golden set (mine from merged PRs + production failures)
- **V2**: SWE-bench Pro integration for public claim + private suite for production

**Key insight**: "Agents are replaceable, evals are the control plane." — eval harness is the durable selection layer.
