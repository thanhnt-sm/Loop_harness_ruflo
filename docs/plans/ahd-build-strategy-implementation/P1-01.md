## 1. Objective

Implement **model tiering** (cheap classifier/router + premium planner/synthesizer) + **per-call-site budget attribution** to achieve 60-95% cost savings:

- Classifier/router (≈300 tokens decision) → cheap model (GLM/Kimi free tier)
- Planner/synthesizer (structured DAG + final answer) → premium model (Lightning)
- Budget bucketed per call-site role: classifier, router, planner, synthesizer
- Alert when any bucket exceeds threshold

### 4.1 router_config.py (New Module)

```python
"""Model Tiering Configuration — cheap vs premium per call-site role.

Based on BUILD_ORCHESTRATION (R3): classifier/router ≈300 tokens → cheap model
Planner/synthesizer → premium model.
"""

from __future__ import annotations
from dataclasses import dataclass
from typing import Literal

CallSiteRole = Literal["classifier", "router", "planner", "synthesizer", "general"]

# Model tiers
CHEAP_MODELS = ["glm-executor", "kimi-executor"]  # Free tier
PREMIUM_MODELS = ["lightning-executor"]  # Paid, high performance

# Role → Tier mapping
ROLE_TIER_MAP: dict[CallSiteRole, Literal["cheap", "premium"]] = {
    "classifier": "cheap",
    "router": "cheap",
    "planner": "premium",
    "synthesizer": "premium",
    "general": "cheap",  # default
}

# Budget buckets per role (USD per session)
ROLE_BUDGET_BUCKETS: dict[CallSiteRole, float] = {
    "classifier": 0.50,   # ~$0.50 for classification decisions
    "router": 0.50,       # ~$0.50 for routing decisions
    "planner": 5.00,      # ~$5.00 for planning (complex DAG)
    "synthesizer": 2.00,  # ~$2.00 for synthesis
    "general": 1.00,      # fallback
}

# Alert threshold (80% of bucket)
BUDGET_ALERT_THRESHOLD_PCT = 80
```

def select_executor_by_role(role: str, task_description: str) -> dict:
    """Select executor based on call-site role + task type."""
    tier = ROLE_TIER_MAP.get(role, "cheap")
    if tier == "cheap":
        # Force free tier executors
        return select_from_cheap(task_description)
    else:
        # Use premium
        return select_from_premium(task_description)
