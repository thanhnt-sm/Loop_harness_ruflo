## 4. Implementation Details

### 4.1 post_tool_config.py — New Constants

```python
# P1-04: Adaptive WM + Prefix-Cache Compaction
# Context window sizes per model (tokens)
MODEL_CONTEXT_WINDOWS = {
    "default": 8192,
    "glm-5.2": 200000,
    "kimi-k2.7": 128000,
    "lightning": 200000,
    "small": 8192,
}

# Auto WM budget: 80% of (window - reserved)
WM_BUDGET_FRACTION = 0.8
RESERVED_TOKENS_HEADROOM_PCT = 0.20  # 20% headroom

# Compaction pressure thresholds
COMPACT_AT_CONTEXT_FRACTION = 0.5   # trigger at 50% usage
RETAIN_CONTEXT_FRACTION = 0.15      # retain 15% newest after compact

# Prefix-cache: pinned items that must remain byte-identical
PREFIX_CACHE_ITEMS = [
    "system_prompt",      # static identity + tools
    "pinned_memory",      # critical facts
    "tool_schemas",       # tool definitions
]
```

### 4.2 context_compaction.py — Extended

Add to existing module:
- `AdaptiveWM` class: computes budget from model context window
- `PrefixCache` class: tracks pinned items, ensures byte-identical prefix
- `PressureCompactor` class: triggers at context fraction, retains newest
- Integration with existing `_compact_session_state` / `_compact_loop_state`

### 4.3 adaptive_compress.py — Extended

- Add `get_wm_budget_for_model(model)` → auto WM budget
- Add `compact_by_pressure(history, current_usage, budget)` → pressure-based
- Ensure `prefix_stable_hash` used for cache validation
